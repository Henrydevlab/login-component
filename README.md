# Login Component

A modern, accessible login form component built with semantic HTML and responsive CSS.

## Features

- **Responsive Design** — Adapts seamlessly from mobile (375px) to desktop (1440px+)
- **Accessible** — Semantic HTML with ARIA labels, visually hidden labels, and proper focus management
- **Clean UI** — Minimalist design with subtle shadows and smooth interactions
- **CSS Variables** — Easily customizable color palette and typography
- **Interactive Elements** — Hover states, focus indicators, and active button animations

## Getting Started

Simply open `index.html` in your browser or integrate the component into your web project.

### Files

- `index.html` — Form markup with semantic structure
- `style.css` — Styling with CSS custom properties and media queries

## Customization

Edit the CSS custom properties in `:root` to adjust colors, typography, and spacing:

```css
:root {
  --clr-btn-bg: #6e1400;      /* Button background */
  --ff-heading: "Georgia", Georgia, serif;  /* Heading font */
  --space-lg: 2.5rem;         /* Large spacing unit */
  /* ... more properties */
}
```

## Browser Support

Works in all modern browsers that support CSS Grid, CSS custom properties, and flexbox.
